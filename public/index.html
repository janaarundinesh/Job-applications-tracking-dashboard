Start the local server first

Jobby keeps your data in a small Python server on this machine, so opening index.html from Finder cannot reach it. Start the server, then use the dashboard it opens. 

python3 server.py --open

On macOS, double-click Jobby.app in the project folder — it starts the server and opens the dashboard in one step. There is a visible-console version too: Start Jobby.command (macOS) or Start Jobby.bat (Windows).

        Reads the posting's structured job data (schema.org / OpenGraph) and fills the form, including the job description, for you to review. Sites that block automated requests can still be added manually.

        CSV headers like company, role, status, phase, applied_on, source, location, salary, description are recognised, and estimated_match_pct becomes the resume match. A row that names no status or phase is saved to apply, not marked as applied. why_it_matches and important_missing_requirements are kept in the notes. Existing jobs are kept; rows are appended.

        Resume, cover letter and other documents can be attached from the job's detail view after saving.

          The Resume tab's Compile button uses Tectonic, a self-contained LaTeX engine, to build a real PDF. Without one, the editor still renders its own preview and every other part of the tracker works as usual. Installing downloads the official release (about 20 MB) into tools/tectonic/ inside this project — no administrator rights, nothing installed system-wide.
