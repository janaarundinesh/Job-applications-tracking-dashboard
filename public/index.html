Start the local server first

Job Pipeline keeps your data in a small Python server on this machine, so opening index.html from Finder cannot reach it. Start the server, then use the dashboard it opens. 

python3 server.py --open

Or double-click Start Job Pipeline.command (macOS) or Start Job Pipeline.bat (Windows) in the project folder — it starts the server and opens the dashboard.

        Add job

        Fill it in yourself, pull it from the posting, or upload a file.

        Reads the posting's structured job data (schema.org / OpenGraph) and fills the form, including the job description, for you to review. Sites that block automated requests can still be added manually.

        CSV headers like company, role, status, phase, applied_on, source, location, salary, description are recognised. Existing jobs are kept; rows are appended.

        Resume, cover letter and other documents can be attached from the job's detail view after saving.
